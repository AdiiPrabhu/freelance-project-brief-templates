# Freelance Project Brief Templates

Six practical Markdown templates for collecting enough information to scope and quote client work before delivery begins.

## Templates

- [General freelance project brief](freelance-project-brief-template.md)
- [Website design and development brief](website-design-brief-template.md)
- [Logo and visual identity brief](logo-design-brief-template.md)
- [Mobile app development brief](mobile-app-development-brief-template.md)
- [Video production brief](video-production-brief-template.md)
- [Social media campaign brief](social-media-campaign-brief-template.md)

The templates cover outcomes, audience, deliverables, inputs, exclusions, approvals, rights, budget, timing, dependencies, and acceptance criteria. They are deliberately plain Markdown so they can be copied into email, Notion, Google Docs, a CRM, or a project-management tool.

## Hosted workflow

Use [BriefCheck](https://briefcheck.youworkagent.online/client-brief-request?source=github-templates) to turn a template into a private questionnaire link, collect the client response, and review the completed brief before quoting.

You can also [score an existing brief](https://briefcheck.youworkagent.online/?source=github-templates) for common scope gaps directly in the browser. The text stays on the device.

## Before sending the quote

Once the brief is complete, use the [freelance quote review checklist](https://github.com/AdiiPrabhu/freelance-quote-review-checklist) to check deliverable boundaries, client dependencies, revisions, acceptance, payment terms, and change control before sending a fixed price.
